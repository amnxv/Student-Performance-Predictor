# Student Performance Predictor

A beginner-friendly machine learning project that predicts a student's academic performance based on study hours, attendance, previous score, and sleep hours.

## Features

- Student performance prediction
- Machine learning using Decision Tree Classifier
- Interactive Streamlit web interface
- CSV-based student dataset

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit

## How to Run

Install the required libraries:

py -m pip install pandas scikit-learn streamlit

Run the application:

py -m streamlit run app.py

## Project Files

- app.py - Streamlit web application
- main.py - Machine learning model and prediction
- student_data.csv - Student dataset

## Project Purpose

This project was created to understand data handling, model training, prediction, and building a simple machine learning web application.
